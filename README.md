BookVerse!
-----------

An online bookstore application named BookVerse where users can browse books, search for books, add books to their cart, and manage their orders.

Technologies Used
-----------------

1. Frontend
-----------
* React.js
* Redux
* Ant Design
* Axios
* CSS
* JSX

2. Backend
----------

* Node.js
* Express.js
* PostgreSQL

Modules
-------

1. User
-------

* User registration and login
* Browse available books
* Search for books
* Add books to the shopping cart
* Checkout and view order history

2. Admin
---------

* Add new books
* Edit book details
* Delete books
* Search for books
* View customer purchases
